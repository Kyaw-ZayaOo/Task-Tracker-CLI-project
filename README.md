## What is this?
A simple, zero-dependency Python CLI Task Tracker. It lets you manage your to-do list right from the terminal using a quick, numbered menu.

---

## Features
- **Interactive Menu:** Quick options (1-6) to view, add, update, and delete tasks.
- **Auto-Saving:** Saves instantly to a local `task_data.json` file. 
- **Smart Filtering:** View your tasks filtered by `to do`, `in progress`, or `done`.
- **Timestamps:** Automatically logs creation and edit times.
